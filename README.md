# 🔐 AI-Powered Escape Room

## Project Overview
The AI-Powered Escape Room is an interactive game where players communicate with an AI Game Master to solve puzzles, discover clues, and escape from a locked library.

The project uses Google's Gemini API to generate natural language responses and Gradio to provide a simple chatbot interface.

## Objectives
- Develop an interactive AI-powered escape room.
- Use Gemini API for intelligent conversations.
- Create logical puzzles with different stages.
- Track player progress throughout the game.
- Build a user-friendly interface using Gradio.

## Technologies Used
- Python
- Google Gemini API
- Gradio
- Google Colab

## Game Story
Players are trapped inside a mysterious library. They must:
1. Find the hidden brass key behind the painting.
2. Unlock the desk drawer using the key and code 2413.
3. Discover the final exit code 7391.
4. Enter the code to unlock the main exit door.

## How to Run
1. Open the notebook in Google Colab.
2. Add your Gemini API key securely.
3. Run the notebook cells.
4. Launch the Gradio interface.
5. Interact with the AI Game Master and solve the puzzles.
